# Exponential Basic 2.4.0.4 Release Notes

**Release date:** 2026-10-22

Exponential Basic 2.4.0.4 is a small maintenance release.

## Changes

- Updated: `settings/menu.ini` (the copy of the Exponential 6.x kernel's admin menu settings)
  gives each header tab the icon the kernel's own `settings/menu.ini` uses: Content `diagram-3`, Media `images`,
  Users `people`, Webshop `box-seam`, Design `palette`, Setup `gear`, Dashboard `speedometer2`, and documents the
  optional `Icon` setting (drawn by the Exponential 6.x admin4 design before the tab's name; other designs
  ignore it).
- Updated: the version is 2.4.0.4 in `lib/version.php`, `kernel/classes/ezpublish.php` and `documentation/ABOUT.md`.

## Upgrading

Nothing to do beyond replacing the files: no database or configuration change.
