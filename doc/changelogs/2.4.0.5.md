# Exponential Basic 2.4.0.5 Release Notes

**Release date:** 2026-10-24

Exponential Basic 2.4.0.5 is a small maintenance release.

## Changes

- Updated: `composer.json` replaces `se7enxweb/ezpublishbasic`, the name this package was published under before.
  It is abandoned on Packagist with `se7enxweb/exponentialbasic` as its replacement. A project that still requires
  the old name resolves to this package alone, and the abandoned name stays out of `composer.lock`, so
  `composer audit` has nothing to report for it.
- Updated: the version is 2.4.0.5 in `lib/version.php`, `kernel/classes/ezpublish.php` and `documentation/ABOUT.md`.

## Upgrading

Nothing to do beyond replacing the files: no database or configuration change.
